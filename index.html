Arsitektur & Berkas Proyek

Proyek dibangun dengan arsitektur frontend–backend terpisah. Berkas wajib UAS berada di folder ini:

  • index.html · style.css · script.js — halaman pengantar & pengecek status API ini
  • koneksi.php — koneksi PDO ke database (dipakai seluruh endpoint API)
  • data.sql — skema & data awal (PostgreSQL)
  • laporan.pdf — panduan penggunaan aplikasi
  • link-github.txt — tautan repositori kode lengkap

Antarmuka aplikasi yang sesungguhnya dibangun dengan React (Vite) dan mengonsumsi REST API PHP di folder api/. Kode lengkap ada di repositori GitHub.

Cara Menjalankan

Backend (PHP + PostgreSQL)

docker compose up --build
# API: http://localhost:8000/api
# Cek: GET http://localhost:8000/api/health

Frontend (React + Vite)

npm install
npm run dev
# Aplikasi: http://localhost:5173
