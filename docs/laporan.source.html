1. Pengantar

NilaiKu adalah aplikasi berbasis web untuk merekapitulasi nilai mahasiswa. Aplikasi menangani seluruh alur penilaian: dosen menginput komponen nilai, admin memverifikasi dan mempublikasikan, dan mahasiswa melihat transkripnya. Nilai akhir dihitung otomatis dari empat komponen (kehadiran, nilai harian per pertemuan, UTS, dan UAS).

Aplikasi memenuhi keempat kriteria soal: (1) aplikasi web rekapitulasi nilai, (2) input data yang valid, (3) role/hak akses berjenjang, dan (4) laporan berupa transkrip serta rekap nilai.

5. Model Penilaian per Pertemuan

Nilai akhir dihitung dari empat komponen dengan bobot:

KomponenBobotSumber
Kehadiran10%Persentase hadir dari total pertemuan (otomatis dari presensi)
Nilai Harian20%Rata-rata skor pertemuan yang sudah dinilai (pertemuan kosong dikecualikan)
UTS30%Diinput dosen
UAS40%Diinput dosen

Nilai akhir = 0,10·Kehadiran + 0,20·Nilai Harian + 0,30·UTS + 0,40·UAS. Contoh: kehadiran 100, harian 85, UTS 80, UAS 90 → 10 + 17 + 24 + 36 = 87.

6. Panduan Penggunaan per Peran

a. Dosen

  1. Masuk menggunakan akun dosen, lalu buka menu Kelas Saya dan pilih kelas.
  2. Klik Kelola presensi untuk membuat pertemuan dan mencatat kehadiran mahasiswa (Hadir/Terlambat/Izin/Alpha).
  3. Klik Nilai harian, pilih pertemuan, lalu isi skor tiap mahasiswa. Pertemuan yang dikosongkan tidak dihitung dalam rata-rata harian.
  4. Klik Kelola nilai. Kolom Kehadiran & Nilai Harian terisi otomatis; dosen cukup mengisi UTS dan UAS. Nilai akhir & huruf muncul otomatis.
  5. Klik Simpan (draf), lalu Kirim untuk mengajukan nilai ke admin.

b. Admin

  1. Masuk menggunakan akun admin. Menu Mahasiswa, Dosen, Mata Kuliah, Kelas untuk mengelola data master (tambah/ubah, filter, pagination).
  2. Buka menu Nilai untuk melihat nilai yang dikirim dosen.
  3. Untuk nilai berstatus Dikirim: pilih Verifikasi atau Kembalikan (dengan catatan).
  4. Untuk nilai berstatus Terverifikasi: pilih Publikasikan agar dapat dilihat mahasiswa.

c. Mahasiswa

  1. Masuk menggunakan akun mahasiswa.
  2. Buka menu Nilai untuk melihat rincian per mata kuliah (Kehadiran, Harian, UTS, UAS, nilai akhir, dan huruf).
  3. Hanya nilai yang sudah dipublikasikan admin yang tampil. IPK/IPS dihitung dari nilai yang terbit.

7. Validasi Data

  • Seluruh input skor dibatasi 0–100 dan divalidasi baik di sisi klien maupun server (menolak nilai di luar rentang).
  • Form data master memvalidasi kelengkapan field wajib sebelum menyimpan.
  • Aksi nilai dibatasi sesuai status alur kerja (mis. nilai yang sudah dipublikasi tidak dapat diubah dosen).

8. Alur Status Nilai

Draf → Dikirim → Terverifikasi → Dipublikasi. Jika ada kekeliruan, admin dapat Mengembalikan nilai ke dosen disertai catatan perbaikan.
